RICK ALLEN RUALO — XAMPP FIXED HTML PORTFOLIO
================================================

EXACT XAMPP LOCATION
Copy this entire "rickportfolio" folder to:

C:\xampp\htdocs\rickportfolio\

Then start Apache and open:

http://localhost/rickportfolio/

FOLDER STRUCTURE
rickportfolio/
├── index.html
├── assets/
│   ├── style.css
│   └── script.js
└── images/
    ├── profile.jpg              <-- PUT YOUR PHOTO HERE
    ├── profile-placeholder.svg
    └── PUT-YOUR-PICTURE-HERE.txt

PROFILE PHOTO
1. Put your picture inside the "images" folder.
2. Rename it exactly:
   profile.jpg
3. Refresh the page.

If profile.jpg is missing, the website automatically displays the placeholder
instead of showing a broken image.

IMPORTANT
This version is HTML/CSS/JavaScript. It does not require PHP to display.
The contact form is a demo and does not send email by itself.

If you previously have an old "rickportfolio" folder in htdocs, delete or
rename it first, then extract this new one so the correct CSS and assets are
used.
